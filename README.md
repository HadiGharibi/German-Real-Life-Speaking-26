## Structure
Each lesson has a stable ID and is stored as a separate Markdown file in `lessons/` so the curriculum can be continued, reviewed, and exported later.

When a new lesson is added, updating the lesson file, `INDEX.md`, `README.md`, and course progress is one atomic publication workflow. A lesson is not considered fully published until all required course navigation/state files are updated and verified.
